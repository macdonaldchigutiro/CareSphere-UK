# Icons Directory

This directory contains icon assets for CareSphere UK.

## Required Icons

1. **Favicon** (`favicon.ico`, `favicon-16x16.png`, `favicon-32x32.png`)
2. **Apple Touch Icon** (`apple-touch-icon.png`)
3. **Android Chrome Icons** (`android-chrome-192x192.png`, `android-chrome-512x512.png`)
4. **Social Media Icons** (Facebook, Twitter, LinkedIn)
5. **App Icons** for mobile PWA

## How to Generate

Use a favicon generator like:
- https://realfavicongenerator.net/
- https://favicon.io/

Place all generated icons in this directory.
